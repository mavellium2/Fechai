# Contatos — Padrões

- Reutilize `getOrCreateConversation` para deduplicar o contato pelo telefone na conta.
- Reutilize `sendManualReply` para gravar a autoria humana e pausar o agente. Os formulários modais mantêm o feedback inline, conforme [o guia de toasts](../../../src/components/ui/toast/TOASTS.md).
