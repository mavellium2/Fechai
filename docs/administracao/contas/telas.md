# Gestão de contas — Telas

- A lista permite pesquisar, filtrar e abrir o gerenciamento de uma conta. A partir dele, o superadmin pode alterar plano e recursos, acessar como usuário ou baixar o JSON.
- **CRM do Fechai**, no gerenciamento da conta, controla o acesso ao funil. A tela informa o preparo na ativação e mantém o histórico ao desligar o acesso. Veja o [fluxo do CRM](../../painel/crm/telas.md).
- A confirmação de exclusão aparece após suspender a conta.
