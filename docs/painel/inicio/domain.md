# Início — Domínio

- `Conversation.needsHuman` sinaliza atendimento que pede intervenção. O painel exibe essas conversas com acesso ao histórico.
- `getOnboardingSteps` lê o progresso de configuração. `requiredSteps` determina quais etapas contam para concluir a lista.
- A saúde combina disponibilidade do agente, WhatsApp e uso mensal retornado pelo módulo de cobrança.
